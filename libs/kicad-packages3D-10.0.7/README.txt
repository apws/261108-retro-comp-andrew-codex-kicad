These STEP files are the KiCad 10.0.7 models named by the footprints on this board,
from https://gitlab.com/kicad/libraries/kicad-packages3D/-/tree/10.0.7

License: Creative Commons Attribution-ShareAlike 4.0 International (CC-BY-SA-4.0).
Only the models this board references are included.

The board and the vendored footprints name them with
${KIPRJMOD}/libs/kicad-packages3D-10.0.7/
so the path is the project directory, not the KiCad Configure Paths
variable KICAD10_3DMODEL_DIR. The mounting holes have no model
in the official footprint.
