== Opening and checking a clone

Clone with Git so the relative `libs` symlinks are preserved. Open link:../layouts/04-freerouting/Z80_Simple_Computer.kicad_pro[the completed FreeRouting project] in KiCad 10. The required library subset and STEP models are included. Upstream library attribution remains in each `libs/*/README.txt`; provenance and adapted-code attribution remain with the project sources and notes.

On a Linux system with KiCad's `pcbnew` Python bindings, use the Python interpreter that can import them. The following commands inspect the saved outputs; they do not reroute the boards. Some update their JSON verification reports.

[source,shell]
----
/usr/bin/python3 tools/check_schematic.py
/usr/bin/python3 tools/sync_layouts.py --check
/usr/bin/python3 tools/check_routing.py --layout 01-reused-agy-router
/usr/bin/python3 tools/check_routing.py --layout 02-codex-router
----

The FreeRouting checker also verifies the exact routing-engine JAR. The downloaded JAR is intentionally excluded from Git. Restore the pinned official release before running that checker:

[source,shell]
----
mkdir -p tools/.cache/freerouting
curl -fL --output tools/.cache/freerouting/freerouting-2.5.0.jar https://github.com/freerouting/freerouting/releases/download/v2.5.0/freerouting-2.5.0.jar
echo 'f6f51bb02245e8e717f9359bd260cc9c5c0b1bc0acc8b7cb2cd5b8ffeb5de3c7  tools/.cache/freerouting/freerouting-2.5.0.jar' | sha256sum --check
/usr/bin/python3 tools/check_freerouting.py
----

KiCad window-state files, Python bytecode, compiled router caches, engine runtime profiles and process IDs are ignored. Native project files, reports, DSN/SES results, MCP request/response evidence and diagnostic logs are retained. Historical logs contain the paths used during the original run; current Python tools derive their project root from their own location.

Do not start a new routing run in the preserved evidence directories without first making a new experiment workspace. In particular, `tools/freerouting_mcp.py` refuses the saved `STOP` marker; removing it and reusing the old inbox is not a clean reproduction. The completed result can be reviewed without starting any server.
