= Fourth routed tracks -- lower address and chip selects
:toc:
:toclevels: 2

This pass routes the fourth signal group: the memory and I/O chip-select decodes
generated by `U7` (74HCT14) and `U8` (74HCT32), plus the lower address lines
(`A0`, `A1`, `A2`) that select internal registers across all peripheral and memory ICs.


== What was routed

Nine nets (17 connections) were routed in this pass:

[cols="1,2,3",options="header"]
|===
|Net |Nodes |Description

|`/~{A15}`
|`U7:8` -> `U8:13`
|Inverted A15 for upper 32K RAM decode.

|`/~{A7}`
|`U7:6` -> `U8:5`
|Inverted A7 for UART I/O port decode.

|`/~{PIOCS}`
|`U8:3` -> `U4:6`
|Active-low chip select to 82C55 PIO pin 6.

|`/~{ROMCS}`
|`U8:8` -> `U3:20`
|Active-low chip select to 27C256 ROM pin 20.

|`/~{RAMCS}`
|`U8:11` -> `U2:20`
|Active-low chip select to 62256 SRAM pin 20.

|`/~{UARTCS}`
|`U8:6` -> `U5:14`
|Active-low chip select to 16C550 UART pin 14.

|`/A0`
|`U5:28` -> `U1:30` -> `U2:10` -> `U3:10` -> `U4:9`
|Address bit 0 (register select).

|`/A1`
|`U5:27` -> `U1:31` -> `U2:9` -> `U3:9` -> `U4:8`
|Address bit 1 (register select).

|`/A2`
|`U5:26` -> `U1:32` -> `U2:8` -> `U3:8`
|Address bit 2 (register select).
|===
