= Third routed tracks -- data bus D0-D7
:toc:
:toclevels: 2

This pass routes the third signal group: the 8-bit bidirectional data bus
(`D0` through `D7`) linking all five major digital chips on the board.


== What was routed

Each data bit connects five dual-in-line packages in parallel across the board:

* `U5`: 16C550 UART (leftmost chip, X ≈ 37 mm)
* `U1`: Z80 CPU (X ≈ 56 mm)
* `U2`: 32K SRAM (X ≈ 74–90 mm)
* `U3`: 32K ROM (X ≈ 93–108 mm)
* `U4`: 82C55 PIO (rightmost DIP, X ≈ 149 mm)

== Routing topology & enhancements

* **Dual-grid obstacle model**: `tools/route_netgroup.py` was enhanced with separate pad and track obstacle grids. Newly routed tracks permanently reserve their clearance zones and cannot be unmasked or grazed by subsequent nets.
* **X-coordinate sorting**: Multi-pin nodes are sorted left-to-right (`X` order), allowing the Steiner tree expansion to build a continuous horizontal backbone across the board.
* **Layers**: Horizontal bus spans run on `F.Cu` with vertical escape stubs and layer transitions on `B.Cu`.
* **Planes**: Inner layers In1.Cu (`GND`) and In2.Cu (`+5V`) were refilled with thermal relief connections maintained.
