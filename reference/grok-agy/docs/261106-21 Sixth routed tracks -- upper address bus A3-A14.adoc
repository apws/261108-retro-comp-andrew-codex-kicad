== Router Enhancement: Roundrect Pin 1 Clearance

KiCad uses `PAD_SHAPE_ROUNDRECT` (shape enum value 4) for Pin 1 on dual-in-line
IC footprints. Previous router passes checked `pad.GetShape() == pcbnew.PAD_SHAPE_RECT`
(value 1), falling back to circular radius approximation for roundrect pads.
Because square/roundrect pads extend further along the diagonal corners
($\sqrt{0.8^2 + 0.8^2} \approx 1.131$ mm vs $0.80$ mm along axis), tracks shaving past
the corner of Pin 1 on `U3` caused a netclass clearance violation.

`tools/route_netgroup.py` was enhanced to treat `PAD_SHAPE_ROUNDRECT` identically
to rectangular pads for exact Chebyshev box distance calculation, preventing any
diagonal corner encroachment.
