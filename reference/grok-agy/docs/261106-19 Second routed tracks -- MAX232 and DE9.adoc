= Second routed tracks -- MAX232 and DE9
:toc:
:toclevels: 2

This pass routes the second signal group: the MAX232 charge pump capacitor loops,
the RS-232 serial lines to the DE9 connector, and the TTL level serial lines
between the MAX232 and the 16C550 UART.


== What was routed

Fourteen point-to-point nets were routed in this pass:

[cols="1,2,3",options="header"]
|===
|Net |Nodes |Description

|`/C1P`
|`U6:1` -> `C20:1`
|Charge pump 1 positive terminal.

|`/C1M`
|`U6:3` -> `C20:2`
|Charge pump 1 negative terminal.

|`/C2P`
|`U6:4` -> `C21:1`
|Charge pump 2 positive terminal.

|`/C2M`
|`U6:5` -> `C21:2`
|Charge pump 2 negative terminal.

|`/VS_PLUS`
|`C23:1` -> `U6:2`
|+10V generated supply rail filter capacitor.

|`/VS_MINUS`
|`U6:6` -> `C24:2`
|-10V generated supply rail filter capacitor.

|`/TX_RS232`
|`J1:3` -> `U6:14`
|Transmitted RS-232 signal to DE9 pin 3.

|`/RX_RS232`
|`J1:2` -> `U6:13`
|Received RS-232 signal from DE9 pin 2.

|`/DTR_RS232`
|`J1:4` -> `U6:7`
|Data Terminal Ready RS-232 handshake to DE9 pin 4.

|`/DSR_RS232`
|`J1:6` -> `U6:8`
|Data Set Ready RS-232 handshake from DE9 pin 6.

|`/TX_TTL`
|`U6:11` -> `U5:11`
|TTL serial transmit line from 16C550 (`SOUT`) to MAX232 driver.

|`/RX_TTL`
|`U6:12` -> `U5:10`
|TTL serial receive line from MAX232 receiver to 16C550 (`SIN`).

|`/DTR_TTL`
|`U6:10` -> `U5:33`
|TTL Data Terminal Ready from 16C550 (`/DTR`) to MAX232.

|`/DSR_TTL`
|`U6:9` -> `U5:37`
|TTL Data Set Ready from MAX232 to 16C550 (`/DSR`).
|===


== Verification and DRC

The route was generated by `tools/route_netgroup.py --group group2` using JLCPCB 4-layer
rules (0.15 mm track, 0.15 mm clearance, 0.70 mm via with 0.30 mm drill). Inner ground
and +5V copper zones were automatically refilled.

DRC check with `kicad-cli pcb drc --schematic-parity`:

* **0 clearance violations**
* **0 shorting items**
* **0 hole clearance violations**
* **0 dangling tracks**
* **0 schematic parity issues**
* Unconnected items dropped from 127 down to **113**.
* Total track segments and vias on the board: **181**.
