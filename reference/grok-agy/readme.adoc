= Z80 simple computer
:toc:
:toclevels: 2

The schematic is the rebuilt sheet. It opens, it uses stock KiCad 10.0.7 symbols, and the parts now sit inside the paper. The notes under `docs/` say how that was done.

The PCB file in this directory is not the posted board. That file would not open, and it is kept unchanged in `as-posted/`. The project board is a new KiCad 10 board. What is on it now is the Eurocard outline, the parts placed on the top, four layers, the inner ground and +5V planes, and all signal tracks 100% routed. The DE9 plug hangs off the left edge. The screw-terminal holes hang off the right edge. The STEP models are in `libs/kicad-packages3D-10.0.7/`, and the board names them with `${KIPRJMOD}`, the project directory.

The choices for this trial are in the plan. The sheet is A3, because the DIP-40 symbols do not fit A4. The board is a 160 by 100 mm Eurocard, four layers, a screw terminal for +5V, four M3 holes, and tracks written into the board file. FreeRouting was not used.

Tooling timeline:

* *Schematic rebuild, placement, and 3D modeling*: Conducted collaboratively using `grok-cli` (Grok 3 in terminal).
* *Automated PCB routing*: Handed over to Google Antigravity (`agy`), using an in-tree Python Manhattan router (`tools/route_netgroup.py`) via KiCad's `pcbnew` Python API.

Routing status:
All signal net groups have been routed and verified via KiCad DRC with 0 clearance violations, 0 shorts, and 0 unconnected items (100% routed):

. Group 1 (clocks and reset) is routed cleanly with 0 DRC errors.
. Group 2 (MAX232 charge pump, DE9 serial, and UART TTL lines) is routed cleanly with 0 DRC errors.
. Group 3 (Data bus D0-D7 across CPU, RAM, ROM, PIO, and UART) is routed cleanly with 0 DRC errors.
. Group 4 (Lower address A0-A2 and chip-select decodes) is routed cleanly with 0 DRC errors.
. Group 5 (Control strobes /RD, /WR, /MREQ, /IORQ and decode inputs A7, A15) is routed cleanly with 0 DRC errors.
. Group 6 (Upper address bus A3-A6, A8-A14 across CPU, RAM, and ROM) is routed cleanly with 0 DRC errors.
. Group 7 (UART BAUDOUT loop and PIO Port A, Port B, Port C headers J2, J3, J4) is routed cleanly with 0 DRC errors. Board unconnected items: 0.

`tools/build_schematic.py` rewrites the schematic. If you move a part in KiCad and then run that script, the script wins. Either edit in KiCad and stop using the script, or change the script. Do not do both.
