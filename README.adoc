This repository preserves three completed routing experiments on the same 160 x 100 mm, four-layer Z80 board placement. All three completed boards passed fresh native ERC/DRC/connectivity/parity checks before the initial Git snapshot. Variant 3 is the prepared native interactive experiment and remains pending. These are design experiments; hardware and signal integrity have not been qualified. FreeRouting's separate CLI controls remained incomplete and are retained as evidence.

The repository includes the required symbol, footprint and STEP library subset. Clone it with Git to preserve the relative library symlinks. The projects were checked with KiCad 10.0.8. [source,shell]
----
python3 tools/sync_layouts.py --check
python3 tools/sync_layouts.py --sync
python3 tools/sync_layouts.py --sync --layout 01-reused-agy-router
----

Edit circuit connectivity in `design/`. Layout schematic snapshots are managed copies; the synchronizer refuses local edits. It preserves each existing layout project file and PCB. Set an experiment's `frozen` manifest flag to retain a historical schematic input. See the organization plan for library-link portability, board update requirements, and fair comparisons.

The current capture uses `design/circuit.json` for pin assignments and `tools/build_schematic.py` for drawing geometry. Regeneration with `python3 tools/build_schematic.py --write` preserves deterministic component UUIDs and refuses unreviewed edits to the generated schematic. If adopting manual KiCad schematic editing, stop regeneration and maintain the `.kicad_sch` directly; synchronization still copies that authoritative file normally.
